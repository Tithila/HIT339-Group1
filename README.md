# Library Management System
This repo contains the improved Library Management System that was initially developed for Assignment 2. These improvements include multi-branch ecosystem, self service Kiosk UI, automated notifications, waitlist queues and advanced administrative data imports.

# Prerequisites
To run this project locally on your computer please ensure you have the following installed:

1. Visual Studio with ASP.NET and Web Development workload
2. .NET 10 SDK

# Intallation

1. Clone the GitHub repo onto Visual studio
2. Right click on: Solution 'LibraryManagementSystem' (The entry at the top of the list in the Solutions Explorer) and select "Restore NuGet Packages"
3. Go to Tools > NuGet Package Manager > Package Manager Console and run: Update-Database in the console that opens.
4. Hit F5 or the green play button towards the top of Visual Studio to start the server and your default browser will open automatically and launch the application.
